# 步数塌缩：生成模型的"债"可以一次性还清

> 源材料：MGFlow / 一步生图论文拆解（清华刘淼团队 + DeepSeek；FLUX.2 4B 后训练一步化实证）
> 本文为 `step-collapse` 技能的方法论底座；可执行工作流见 `../SKILL.md`。

## 一、奥卡姆剃刀下的主题

剥掉"多模态加速""一步生图""大模型军备竞赛"这些外壳，能站住的最小假设只有一条：

**过去生成模型要用四步、十步去迭代，不是因为"画得慢"，而是因为在"分布建模的粒度"上欠了债——步数是在还债。粒度一旦可调且对齐到位，债就一次性还清，步数自然塌缩成一步。**

其余全是这条的推论：MGFlow 是还债工具，FLUX.2 4B 被后训练成一步是还债结果，DeepSeek 招人做多模态是开始借新债。

## 二、核心分点提炼

### ① 统一框架｜把两套对立手艺，收进同一张图纸

此前 FD-Loss 与 Gaussian-kernel Drifting 被当成两种独立路线。论文指出它们只是同一框架下选了不同"分布模型 + 差异度量"：FD-Loss = 单高斯 + W2 最优传输；Drifting = 核密度估计 + KL 散度。理论打通后，中间档位才可能被制造出来。

### ② 高斯混合｜粒度从"两个极端"变成"可调节"

单高斯只能抓全局均值方差，猫狗飞机被揉成一团；纯样本核方法能抓局部却丢全局协方差、易模式坍塌。MGFlow 用 K 个高斯组件拼接拟合真实特征，K 可自由设（1/4/16 多分辨率并行），粗粒度全局约束与细粒度局部约束同时生效。

### ③ 模式崩溃｜真正的病根不是表达力不够

加组件数量治标不治本——子模式分得太开时会出现"分数失明"：某一类物体生成数量严重偏少，梯度信号却微弱到看不见。病根是样本与组件之间缺硬性约束。解法两块：一是 LP 线性规划质量约束，强制分给每个组件的样本总质量等于真实世界该模式的权重（猫占 5% 就锁死 5%）；二是配对组件更新，生成侧第 k 个组件只对齐真实侧第 k 个，不做全局笼统匹配。

### ④ 实验结果｜一步打赢四步

ImageNet 256×256 上，MGFlow-KL、JiT-H 相对 FD-Loss 基线分别提升 23%、38%，FDr⁶ 达 1.45 / 1.64。文生图方向，对 FLUX.2 4B 做后训练改造成一步生成器，在 GenEval 与 PickScore 上均优于原四步模型。技巧上还把图文特征拼接，直接对齐图文联合分布以强化提示词匹配。

### ⑤ 工程细节｜不给模型"摆烂"的机会

过去 FD-Loss 的归一化系数跟着当前生成质量动态变化——生成越烂，难拟合维度权重被自动压低，等于自我开脱。MGFlow 改用真实训练集与验证集的固定差值做归一化系数。

## 三、未来现实行动指南：怎么塞进工作流

### 第一步：把"步数"当成可调成本项，而不是固定配置

你的出图管线里，步数是可压缩项而非质量保险。建立一张对照表：步数 vs 延迟 vs 质量分。凡是"实时预览、批量出草稿、A/B 选样"的场景，直接换一步模型；只在终稿精修时保留多步迭代，把算力花在刀刃上。

### 第二步：优先用"后训练改造"，别从头训

论文最关键的可复用点在这儿——已训练好的多步模型，通过后训练微调即可改造成一步生成器。这意味着你不需要重训底座，只需在有 FLUX 类开源底座上做一轮轻量级后训练。落地动作：把你现有的出图模型列出来，标注哪些支持后训练接口，排一个"四步→一步"的改造队列。

### 第三步：盯住三个真正能上生产的新场景

一步生成的价值不在"更快一点"，而在打开原本不可能的场景：低延迟交互（边说边出图）、端侧部署（手机/浏览器本地跑）、大批量快速渲染（电商主图、素材海选）。按这三条去挑你业务里最先受益的口子，别一上来就追求画质超越原模型。

### 第四步：如果你做数据/评测，补一个"模式覆盖度"指标

论文戳破的痛点值得迁移：常规指标（FID、PickScore）看不出"某一类悄悄消失了"。给你的评测集加一条类别配额覆盖率——生成 N 张里，各类别占比是否逼近真实分布。这是发现"分数失明"的廉价探针。

### 第五步：把这次的方法论抽象成通用动作

这套解法的外壳是生图，内核是通用的三步：统一框架 → 找中间粒度 → 加硬性约束。你遇到任何"两派方案各走极端"的问题（推荐里的全局模型 vs 个体模型、风控里的规则 vs 模型），都可以照抄：先 unify 成一个框架，再在两端之间造可调节粒度，最后用约束锁死分配，防止系统自发走向坍塌。

## 一句话收尾

**别只记住"四步变一步"，记住"债是可以一次性还清的"——先问你的流程里，哪几个迭代步骤是在补同一个缺陷。**
